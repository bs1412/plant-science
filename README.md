# 植物简单科普 🌿

一个多页面的植物科普静态网站，包含植物生长知识、植物图鉴、园艺技巧、植物猜谜、植物趣谈等内容。

> Web 前端课程作品，纯 HTML + CSS + JavaScript 实现。

## ✨ 页面

- 首页（轮播图 + 文案）
- 植物生长科普
- 植物图鉴
- 园艺技巧
- 植物猜谜
- 植物趣谈
- 登录 / 注册

## 🛠️ 技术点

- 多页面结构与导航
- CSS 布局与样式（弹性布局、轮播图）
- 原生 JavaScript 交互（图片切换、表单校验等）
- 本地图片与视频素材的使用

## 🚀 如何查看

直接用浏览器打开 `index.html`，或用 VS Code 的 Live Server 插件预览。

## 📂 目录结构

- `*.html` —— 各页面
- `css/` —— 样式
- `js/` —— 脚本
- `img/` —— 图片与视频素材
